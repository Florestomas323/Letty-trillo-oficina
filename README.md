# Oficina Digital — Letty Trillo (ALFA SUR-AMÉRICA)

Sitio de distribuidora independiente de Royal Prestige. HTML plano, sin build.
Dominio: lettytrillo.com · Firebase: letty-trillo-oficina

## Antes de publicar

`node validar.js` debe decir LIMPIO. Vercel lo corre como build: si bloquea, no publica.

## Variables de entorno en Vercel

RESEND_API_KEY · CORREO_AVISOS · FIREBASE_SERVICE_ACCOUNT · VAPID_PUBLICA · VAPID_PRIVADA

Ninguna de estas va en el repositorio.

## Ojo: las imágenes

Todas las fotos van en la raíz junto a los .html (hero-letty.jpeg, hero-letty-movil.jpeg,
fondo-textura.jpeg, foto-*.jpg, og-*.jpeg, iconos) y en assets/trabaja/.
Si subes por la web de GitHub, arrástralas en un segundo envío: el navegador suele
quedarse corto cuando son muchos archivos y las deja fuera sin avisar.
